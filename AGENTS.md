# Project instructions

This project is a single-file web app for GitHub Pages. Keep `index.html` at the project root and put the app implementation there.

## Layout

- `AGENTS.md`, `spec.md`, `prompts.md`, and `index.html` belong at the project root. GitHub Pages needs the root-level `index.html`.
- `00_planning/` is for project notes and sketches.
- `01_data/` is for data files.
- `02_validation/` is for hand calculations and test cases.
- `03_output/` is for screenshots and exported results.

Save every new file in the folder that matches its purpose. Keep app code in the root `index.html`; do not add other app source files.

## Git commits

After validating requested project changes, commit them automatically when this project is inside a Git repository. Stage only files belonging to this project and the current task; never include unrelated workspace changes. If no Git repository is available, do not initialize one unless asked.
