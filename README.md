# Beam Designer

An educational Tkinter desktop app for preliminary analysis of a single-span steel W-shape beam. It calculates reactions, shear, moment, and deflection, and provides limited flexural and deflection checks. Designs can be saved or opened; results can be exported to CSV or a calculation-sheet PDF.

## Requirements

Python 3.10 or newer with Tkinter. No third-party Python packages are required. On some Linux systems, install the OS package `python3-tk` if Tkinter is missing.

## Start

```sh
python3 app.py
```

Results are preliminary and educational, not a complete structural design or construction approval.
