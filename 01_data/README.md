# Data

Store project data files here. `w_shapes_v16.json` contains the 289 AISC W-shape
records used by the app, with U.S. customary section properties.

The records are extracted from AISC Shapes Database v16.0 (August 2023). The
official [AISC database page](https://www.aisc.org/aisc/publications/steel-construction-manual/shapes-database-v160/)
describes the free standard database. The pinned extraction snapshot and source
workbook URL are recorded in the JSON metadata; confirm the selected properties
against the official database when updating the catalog. Section properties
describe geometry, not material grade, availability, or design capacity.
